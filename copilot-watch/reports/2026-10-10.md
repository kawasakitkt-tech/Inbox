## 2026-10-10 Copilot デイリー
### 🔥 重要
- **[M365 Copilot] Copilotアプリ内で Word・Excel・PowerPoint を作成・編集・共同編集できる「Office in Copilot」が提供開始**（Frontier（先行提供））
  - Copilotアプリ（Chat／Cowork）の中で、Office本来の編集・共同作業機能を使って文書・表・資料を仕上げられるようになります。
  - Chatで依頼すると Word文書などが会話の横に開き、フォローアップのプロンプトや直接編集で仕上げられる（会話履歴は保持）
  - 共有・コメント・共同編集・プレゼンス（誰が編集中か表示）が同じ画面で使え、変更はリアルタイム反映
  - 「Library」で Word/Excel/PowerPoint の最近のファイル、ページ、AI生成画像を一覧・再開できる。ファイルは OneDrive 保存で、書式・コメント・権限・バージョン履歴とセキュリティラベル等のガバナンスを継承
  - モデルは選択または Auto 任せにできる。PowerPoint のブランド維持・テンプレ適用、Excel の変更レビュー・グラフ推奨、Skills／コネクタも利用可
  - 提供は Frontier 顧客向けで ChatとCoworkから（記事では「rolling out today」）。一般提供時期は記載なし
  - 実務への影響: Frontier プログラム参加テナントでは、資料作成を Office アプリに切り替えずに Copilot 内で完結できる見込み。一般提供前に、OneDrive 保存と既存の共有・ラベル運用が合うか確認しておく価値があります。
  - 出典: https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/introducing-office-in-the-new-microsoft-copilot-app/4561230 / 検知元: Tech Community（Microsoft Copilot Blog）

#### GitHub Copilot
- **[GitHub Copilot] Copilot code review：組織への課金方式と、レビュー依頼者の制御を追加**（発表）
  - Copilot コードレビューの利用料をメンバー個人ではなく組織に請求でき、外部ライセンスによる依頼も制限できます。
  - 組織設定 Copilot → Policies の「Choose how members with a Copilot license are billed」で Member（既定）か Organization を選択
  - Organization は AI Credits の従量課金有効化が必要で、予算設定も可能。Member でクォータ枯渇時はレビューが失敗
  - 「Only allow Copilot code review to be triggered by authorized users」で、組織・企業提供のライセンス保有者のみ依頼可能に（個人ライセンス等を排除）
  - 組織レベルで有効にするとリポジトリ管理者は無効化できない
  - 出典: https://github.blog/changelog/2026-10-08-copilot-code-review-new-organization-billing-options-and-controls / 検知元: GitHub changelog
