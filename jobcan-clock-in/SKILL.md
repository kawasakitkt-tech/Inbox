description: ジョブカン出勤打刻（平日9時）
---
## 重要: このタスクは必ず Claude in Chrome（ブラウザ拡張機能）を使って実行してください。

- Playwright・Puppeteer・curl・API など他の手段でのブラウザ操作は**絶対に使わないでください**
- Claude in Chrome が接続されていない場合は処理を中止し、「Claude Code Desktop と Claude in Chrome 拡張機能が必要です」とだけ報告して終了してください
- 資格情報（メール・パスワード）を環境変数や設定から探さないでください。パスワードは Chrome の自動入力に任せます

## 手順

1. Claude in Chrome で新しいタブを開き https://id.jobcan.jp/users/sign_in にアクセス
2. Chrome のパスワード自動入力でメール・パスワードが入力されていることを確認し、ログインボタンをクリック
3. 遷移後、画面左上ナビゲーションの「勤怠」をクリック
4. 勤怠画面の「PUSH」ボタンをクリック
5. 打刻完了を確認後、このタスクで開いたタブをすべて閉じる

## 注意

- すでにログイン済みの場合は手順3から開始する
- CAPTCHA や追加認証が出た場合は中断してユーザーに通知する
- 打刻完了後は開いたタブ・グループをすべて閉じること
